Gemini for Google Sheet (C817) — Lab 4: Generate, Explain and Fix Screening Formulas
Sample prompts for Gemini in Google Sheets. Copy one at a time, adapt it, and verify every result.
Prompts web page (one-click Copy): https://tertiarycourses.github.io/C817-Gemini-for-Google-Sheet/prompts/#lab-4

[1] Lookup
Create a formula that returns the Hiring_Manager for the Job_ID in E2 from the Jobs tab (A2:J9).

[2] Date
Create a formula for the number of days between Applied_Date in D2 and the report date in Settings!B1.

[3] Text
Create a formula that returns TRUE if Key_Skills in J2 contains "SQL".

[4] Count
Create a formula that counts Above budget candidates for each Position.

[5] Explain
Explain the difference between VLOOKUP and XLOOKUP, and when to use each.
